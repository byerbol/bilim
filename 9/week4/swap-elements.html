list.pop() · Examples #3 and #4

      
pop() removes an element and gives it back

    

    

      

        
    
          
  • List.pop() removes and returns the last element.
    • 
          
  • List.pop(index) removes and returns the element at that index.
    • 
          
  • The elements after it move one place to the left.
    • 
          
  • If the index is out of range, Python stops with IndexError.

Extra · list.insert()

      
insert(index, value) puts an element back

    

    

      

        
    
          
  • List.insert(1, 99) puts 99 at index 1.
    • 
          
  • The element that was there, and everything after it, moves one place to the right.
    • 
          
  • If the index is bigger than the list, the value goes to the end. No error.
    • 
          
  • pop() and insert() are opposites: one takes out, the other puts in.
    •

Compare

      
Three ways to swap, one result

    

    

      
Third box
temp = List[1]
List[1] = List[3]
List[3] = temp
Works in every programming language. Three lines.

      
Python way
List[1], List[3] = List[3], List[1]
Short and clear. Use this one in your programs.

      
pop() and insert()
a = List.pop(1)
b = List.pop(3 - 1)
List.insert(1, b)
List.insert(3, a)
Longer, but it teaches how lists shift when elements leave and come back.
