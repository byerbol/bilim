Spreadsheet Formulas

How do you calculate the area of a rectangle in a spreadsheet? You write a formula once, and the spreadsheet does the math for you.

  • You willlearn how to write and copy formulas

Keep in mind

Every cell has an address

  • Columns are named with letters: A, B, C, D …
  • Rows are named with numbers: 1, 2, 3, 4 …
  • A cell's name is its column letter, then its row number. The cell in column A, row 1 is A1.
A1column A, row 1

Click any cell in the sheet to see its address.

Formulas

A formula calculates the value of a cell

Spreadsheets mostly work with numbers. A formula can add, subtract, multiply, divide and raise to a power. Every formula starts with =.

    Click an operation to see it in the sheet.

    Enter a formula

    Four steps to your first formula

    1. Type 7 in cell A1 and 3 in cell A2.
    2. Select cell A3.
    3. Type an equal sign = to start a formula.
    4. Then type A1+A2 and press Enter.

    Tip: instead of typing A1 and A2, just click on cell A1 and cell A2 while you write the formula. Try it in the sheet.

    Change a number and the formula updates by itself. This is why we use cell names, not typed numbers.

    Copy / paste a formula

    Copy a formula and it adjusts itself

    1. Enter the formula =A1*(A2+A3) into cell A4.
    2. Select A4 and copy it: right-click > Copy, or Ctrl+C.
    3. Select B4 and paste: right-click > Paste, or Ctrl+V.
    4. B4 now has =B1*(B2+B3) and uses the values from column B.

    The spreadsheet moved every cell name one column to the right, because the formula moved one column to the right.

    Relative and absolute values

    The $ sign stops a reference from moving

    By default, references are relative: copy =A1+B1 from row 1 to row 2 and it becomes =A2+B2. An absolute reference never changes. It is marked with a dollar sign.

    A2The column and row change when copied
    $A$2The column and the row do not change
    A$2The row does not change
    $A2The column does not change

    Try it: copy =A1 from B2 to every cell

    movedlocked with $

    Relative vs absolute in action

    When copying breaks a formula

    To convert TB to GB, MB and so on, every row multiplies by the same constant 1024 in B1.

    • =B2*B1 works in B3. Copy it down, and B1 moves too: B4 becomes =B3*B2. Wrong answer.
    • =B2*$B$1 keeps the constant locked. Copy it down and every row still uses B1.

    Rule of thumb: a value that every copy must share, like a constant or a price, gets $.

    Extra: ready-made functions

    Functions do common math for a whole range

    A2:A6 is a range: every cell from A2 down to A6. Functions take a range in brackets.

    SUM=SUM(B2:B6) adds all the numbers
    AVERAGE=AVERAGE(B2:B6) finds the mean
    MAX=MAX(B2:B6) finds the largest
    MIN=MIN(B2:B6) finds the smallest
    ABS=ABS(A1-B1) removes the minus sign

    Keep in mind

    When a formula shows an error

    Sometimes Google Sheets cannot calculate a cell. Then it shows an error code instead of a number.

    • #DIV/0!Division by zero. It is mathematically undefined.
    • #NAME?A misspelled function, like =SUMM(A1:A2), or text without quotes.
    • #ERROR!The formula is written wrong, like =A1+*2.
    • #REF!A circular reference: the cell uses itself.

    Click an error cell to see its formula. Fix it by changing A2 to a number that is not 0.

    Quick check

    Predict before you type

    Click an answer. The explanation appears when you find the right one.

    C1 has =A1+B1. You copy C1 to C2. What is in C2?

    =A2+B2. One row down, so every row number goes up by 1.

    Which reference never changes when you copy it?

    $A$2. Both the column and the row are locked.

    B1 has =$A1*2. You copy it to C1. What is in C1?

    =$A1*2. The column A is locked, and the row did not move.

    A1 is 10 and A2 is 0. What does =A1/A2 show?

    #DIV/0! You cannot divide by zero.

      Literacy: why is it important to use formulas?

      Discuss first, then open. Formulas update by themselves when the data changes. One formula can be copied to hundreds of rows. They avoid mistakes from calculating by hand, and anyone can click a cell to see how a result was found.
