Draw with Tracy the Turtle

Today you learn three commands that make your drawings thicker, rounder and more colorful.

  • pensize(width)How thick the line is
  • circle(radius)Draws circles and arcs
  • bgcolor("color")Paints the background

On CodeHS the turtle is already loaded, so you do not write import turtle. Just type the commands.

Warm-up recap

Four commands move Tracy

  • forward(100)Walk 100 steps the way Tracy is facing.
  • backward(50)Walk 50 steps back without turning around.
  • left(90)Turn 90 degrees to Tracy's left.
  • right(45)Turn 45 degrees to Tracy's right.
  • color("blue")Change the pen color. Text always goes in quotes.

      

      
    

  







  

    

      
New command 1 of 3

      
pensize(width) sets how thick lines are

    

    

      

        
    
          
  • The number is the width in pixels. Tracy starts with pensize(1).
    • 
          
  • Call it before you draw. Every line after it uses the new size until you change it again.
    • 
          
  • Bigger number, thicker line: pensize(20) is like a marker.
    • 
        

        

        

      

      
    

  







  

    

      
New command 2 of 3

      
circle(radius) draws circles and arcs

    

    

      

        
    
          
  • The center of the circle is radius steps to Tracy's left. So the circle grows up from where Tracy stands when she faces right.
    • 
          
  • Tracy ends exactly where she started, facing the same way.
    • 
          
  • A negative radius, like circle(-50), goes clockwise with the center on the right.
    • 
          
  • Add a second number to draw only part of a circle: circle(50, 180) is a half circle.
    • 
        

        

        

      

      
    

  







  

    

      
New command 3 of 3

      
bgcolor("color") paints the background

    

    

      

        
    
          
  • bgcolor("lightblue") colors the whole canvas. Lines you already drew stay on top.
    • 
          
  • Use a color name in quotes, like "navy" or "pink", or a hex code like "#ffcc00".
    • 
          
  • color() changes the pen. bgcolor() changes the paper.
    • 
        

        

        

      

      
    

  







  

    

      
All together, with a loop

      
Six circles make a flower

    

    

      

        

        
    
          
  • bgcolor("black")Black paper, set once at the start.
    • 
          
  • pensize(3)All lines are 3 pixels thick.
    • 
          
  • for i in range(6):Repeat the indented lines 6 times.
    • 
          
  • circle(80)One circle of radius 80.
    • 
          
  • left(60)Turn a little. 6 × 60 = 360, a full turn.
    •
